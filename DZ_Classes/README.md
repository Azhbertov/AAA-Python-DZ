# ДЗ по классам

Программа считает частоты слов и веса TF-IDF и выбирает ключевые слова текста.

## Требования

Нужен Python 3, сторонние зависимости не требуются, используется библиотека math.

## Запуск

```bash
python hw_classes_base.py
```

## Проверка работы

В hw_classes_base.py функция demo() запускает три проверки.

1. Проверка TF-IDF и независимости копии IDF.
2. Проверка регистра, отключения IDF и нового обучения.
3. Проверка ключевых слов и ограничения top_n.

Тексты для проверок в начале файла в TRAIN_CORPUS и CHECK_CORPUS.
