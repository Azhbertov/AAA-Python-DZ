# ДЗ 2
Программа читает файл Corp_Summary.csv и по заданному варианту готовит отчёт.

## Требования
Нужен Python 3, сторонние зависимости не требуются, используется библиотека csv.

## Запуск
```bash
python DZ_Func_2.py
```
Файлы DZ_Func_2.py и Corp_Summary.csv должны лежать в одной папке.

## Выбор отчёта
По умолчанию в DZ_Func_2.py вырбан третий вариант main(3).
Чтобы выбрать другой вариант, нужно изменить 3 на 1 или 2.
main(1) - для каждого департамента показывет, какие команды в него входят.
main(2) - сводка по департаментам: название, сколько человек, минимальная и максимальная зарплата, средняя по каждому департаменту.
main(3) - то же самое, что в "2", но записанное в csv-файл.
